# Endfield Calculator

一个用于规划《明日方舟：终末地》行列谜题的轻量级桌面求解器，支持 3×3 到 6×6 棋盘，以及游戏中已经存在、无法部署的初始障碍格。

## 功能

- 自动计算所有满足行列目标的部署方案
- 支持添加和移除初始障碍
- 自动检查矛盾目标与无解情况
- 支持 3×3、4×4、5×5 和 6×6 棋盘

## 运行要求

Python 3.10 或更高版本。

## 使用方法

1. 运行 `python main.py`。
2. 点击棋盘上方和左侧的数字设置每列、每行的目标数；右键可以反向调整。
3. 点击棋盘格添加或移除初始障碍。
4. 点击“开始求解”，再用“上一个 / 下一个”浏览全部方案。

障碍格显示为 `×`，求解后的部署位置显示为绿色 `●`。
